# PDF-Toolkit
This is my final project for the course 'Python for Computational Problem Solving' in Semester 1.

PDF Toolkit allows the user to perform the following functions on PDF files:
- <i>extract tables</i> from a PDF file into an excel file
- <i>extract images</i> from a PDF file
- <i>split</i> a PDF file page-wise into separate PDF files
- <i>merge</i> more than one PDF into a single PDF file
- <i>add password</i> protection to a PDF file
- <i>remove password</i> protection from a PDF file

<h3>Backend: Python	</h3>
  • pdfplumber module <br>
  • tempfile module <br>
	• csv module <br>
	• PyPDF2 module (PdfReader, PdfWriter, PdfMerger functions)
